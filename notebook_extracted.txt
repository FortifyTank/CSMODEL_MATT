Some variables, for example Perceived_AI_Dependency, Anxiety_Level_During_Exams, and the weekly hour estimates are self-reported. If a university has a strict rule set, like Institutional_Policy with an outright AI ban, students might report lower AI usage than they actually had, or describe their primary use case in a different way. It can feel like AI is harmless in those datasets but it’s more like the reporting changed.

Like, a student with high Weekly_GenAI_Hours might show an immediate GPA uplift, however the way it gradually compounds, on student burnout and long-term academic growth, needs observations over multiple terms. Otherwise it feels sorta limited, because we do not actually see the longer rhythm.

### A. Formatting Categorical Names and Data Types

--- CELL 30 (Markdown) ---
The first step is to ensure that all the variables were correctly typed and formatted. We checked each of the numerical columns to ensure that no strings were incorrectly mapped, such as finding the string "20" in the weekly Generative AI hours column which is supposed to take a float value. For the categorical columns, we stripped away any accidental whitespaces and standardized the spelling and capitalization by using the difflib library to ensure that the format is consistent across the dataset.

--- CELL 31 (Code) ---
# Check for consistent categorical names
print("Checking For Consistent Categorical Names:\n")
categoricals = []
numericals = []

for col in df.columns:
    if pd.api.types.is_numeric_dtype(df[col]) and not pd.api.types.is_bool_dtype(df[col]): # if variable column is float
        numericals.append(col)

    elif pd.api.types.is_bool_dtype(df[col]): # if variable column is boolean
        categoricals.append(col)

    # catches both 'object' and 'string' data types
    elif pd.api.types.is_object_dtype(df[col]) or pd.api.types.is_string_dtype(df[col]):
        if not df[col].astype(str).str.isdigit().all(): # checks if column is categorical
            categoricals.append(col)

            df[col] = df[col].astype(str).str.strip() # fix whitespace
            raw_counts = df[col].value_counts()

            standard_mapping = {} # standardized the data values
            for unique_val in raw_counts.index:
                lowercase_version = unique_val.lower()
                if lowercase_version not in standard_mapping:
                    standard_mapping[lowercase_version] = unique_val

            # Map values to their most frequent standard casing (e.g. stem to STEM)
            df[col] = df[col].apply(lambda x: standard_mapping[x.lower()])

            legitimate_categories = list(standard_mapping.values())

            def fix_typos(value): # fix spelling (ste to STEM)
                if value in legitimate_categories:
                    return value
                matches = difflib.get_close_matches(value, legitimate_categories, n=1, cutoff=0.5)
                if matches:
                    print(f"Fixed typo from {col}: Changed '{value}' to '{matches[0]}'")
                    return matches[0]
                return value

            df[col] = df[col].apply(fix_typos)

        else: # fix numeric variables ('1' to 1)
            converted_series = pd.to_numeric(df[col], errors='coerce')
            if not converted_series.isnull().all():
                numericals.append(col)
                df[col] = converted_series

max_len = max(len(categoricals), len(numericals))

print(f"{'Index':<6} | {'Categorical Variables':<26} | {'Numerical Variables':<26}")
print("-" * 65)
for i in range(max_len):
    cat_val = categoricals[i] if i < len(categoricals) else ""
    num_val = numericals[i] if i < len(numericals) else ""
    print(f"{i:<6} | {cat_val:<26} | {num_val:<26}")

print("Successfully updated both categorical inconsistencies and numeric type mismatches across all variables\n")

## 5.2 Apriori Algorithm (Association Rule Mining)

--- CELL 83 (Markdown) ---
Apriori Algorithm, a technique for association rule mining, was used to explore patterns. Since this algorithm finds frequent itemsets first, the group set a 1% minimum support due to the size of the dataset (50,000). Then when determining the actual rules, the group determined a 50% minimum confidence would be practical. The library **mlxtend** was used to construct the Apriori algorithm.

--- CELL 84 (Code - Section 5 related) ---
from mlxtend.frequent_patterns import apriori, association_rules

# frequent itemsets with 1% min. support
frequent_itemsets = apriori(boolean_matrix, min_support=0.01, use_colnames=True)

# association rule generation with min. confidence at 50%
rules = association_rules(frequent_itemsets, metric="confidence", min_threshold=0.50)

# rules sorted by "lift". if lift > 1, it indicates positive relationship between antecedent and consequent 
# lift = 1 and lift < 1 indicate independence and negative relationship respectively
rules = rules.sort_values(by='lift', ascending=False)

# top 10 rules sorted by lift
print("Association Rules:")
display(rules[['antecedents', 'consequents', 'support', 'confidence', 'lift']].head(10))

### A. Does the distribution of academic burnout risk vary significantly across different academic major categories?

--- CELL 91 (Markdown) ---
Statistical Method: Chi-Square Test of Independence 

Significance Level: $\alpha = 0.05$

--- CELL 92 (Markdown) ---
**Hypotheses:**
*   **$H_0$ (Null):** There is no significant difference in burnout risk across different academic major categories.
*   **$H_a$ (Alternative):** There is a significant difference in burnout risk across different academic major categories.

--- CELL 93 (Markdown) ---
Data Pre-processing and Justification: We used the original dataset as it was confirmed to be clean after numerous tests. The Chi-Square test was chosen because it is specifically designed for evaluating relationships between categorical data, which perfectly fits both our Academic Major and Burnout Risk variables. Furthermore, because of our massive sample size, we easily meet the test's requirement that every category has a high frequency of data points, allowing for extremely precise and reliable p-values.

--- CELL 95 (Markdown) ---
Important Values: The test yielded a Chi-Square Statistic of 376.27 and an infinitesimally small p-value of 2.22e-76.

--- CELL 96 (Markdown) ---
Conclusion: Because the p-value is astronomically lower than our 0.05 significance level, we strongly reject the Null Hypothesis. This mathematically proves the observation we made in EDA A. It was not random chance; the specific major a student is in genuinely affects their likelihood of experiencing high academic burnout. We therefore conclude that there is a significant difference in burnout risk across different academic major categories.

### C. Is there a correlation between the institutional policy on AI and the anxiety level of students?

--- CELL 105 (Markdown) ---
Statistical Method: One-Way ANOVA (Analysis of Variance) 

Significance Level: $\alpha = 0.05$

--- CELL 106 (Markdown) ---
**Hypotheses:**
*   **$H_0$ (Null):** There is no significant difference in mean exam anxiety levels across the different institutional AI policies.
*   **$H_a$ (Alternative):** At least one institutional AI policy has a significantly different mean exam anxiety level.

--- CELL 107 (Markdown) ---
Data Pre-processing and Justification: We used the original dataset for this test, isolating the categorical `Institutional_Policy` and the continuous `Anxiety_Level_During_Exams`. A One-Way ANOVA was chosen because it is the standard statistical method for comparing the means of three or more independent groups. ANOVA assumes that the data is normally distributed and that the variances among groups are equal. Given our enormous sample size, the Central Limit Theorem satisfies the normality assumption, and ANOVA remains highly robust, making it the perfect test for these variables.

--- CELL 109 (Markdown) ---
Important Values: The test yielded an ANOVA F-statistic of 511.79 and an astronomically low p-value of 9.46e-221.

--- CELL 110 (Markdown) ---
Conclusion: Because the p-value is practically zero and falls far below our 0.05 significance level, we strongly reject the Null Hypothesis. This mathematically proves our visual observation from EDA C. that a strict ban creates a significantly higher level of exam anxiety compared to policies that allow or encourage AI usage. We can therfore conclude that At least one institutional AI policy has a significantly different mean exam anxiety level.

--- CELL 111 (Markdown) ---
Post-Hoc Analysis Justification (Tukey vs. Bonferroni): While the ANOVA test successfully indicated a statistically significant difference in anxiety levels across the institutional policies, it does not specify where the exact differences lie. To find this, a post-hoc test was required. We initially considered the Bonferroni correction as it was discussed in class. However, because Bonferroni is known to be overly conservative (which drastically reduces statistical power), we opted for Tukey's Honest Significant Difference (HSD) test instead. Tukey's HSD is much better suited for this occasion as it provides a superior balance of statistical power while strictly controlling the error rate when comparing all possible pairs of categorical means.

--- CELL 113 (Markdown) ---
Important Values: Strict_Ban comparisons have both relatively high meandiff values.

--- CELL 114 (Markdown) ---
Conclusion: The ANOVA test confirms a statistically significant difference in anxiety levels among the policy groups (p < 0.05). Furthermore, the Tukey Post-Hoc test reveals that students under a "Strict Ban" experience significantly higher anxiety levels compared to those in "Actively Encouraged" or "Allowed with Citation" environments. Conversely, there is no statistically significant difference in anxiety between the "Actively Encouraged" and "Allowed with Citation" policies, as their outcomes are nearly identical.

This strongly supports our earlier assumption that the prompt engineering skills of students are relatively evenly distributed across the different academic years. We therefore conclude that there is no significant relationship between a student's academic year of study and their prompt engineering proficiency.
